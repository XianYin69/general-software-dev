# references（知识库）

本目录存本中枢技能的**跨领域**沉淀：编排判例、门禁经验、路由取舍。

## 应存什么

- 决策卡片：问题 → 判据 → 动作（每张 ≤50 行）；
- 外部资料原始链接清单（GitHub/GitLab/官方仓库/发布页）；
- 流程与状态图（JSON/HTML 皆可，非脚本）。

## 不应存什么

- 各语言专项细节（归被派发技能的知识库，本体不重复收录）；
- 缓存、下载产物、运行态文件（须落用户缓存目录）。
