# 需求确认

## 输入

用户诉求（软件项目目标、约束、交付形态）＋本表行已声明的边界。

## 步骤

1. 复述目标与验收标准，标出缺口；关键缺口用 ask_user 一次一问。
2. 判定路径：新建项目＝创建路径；改已有＝
   [修改流程/](../修改流程/修改流程.md)。
3. 判定语言/栈与专项归属，填路由清单（见
   [子技能路由/](../子技能路由/子技能路由.md)）。
4. 判定哪些环节由本体持有（脚手架/架构/打包/测试/远端），哪些只派发。

## 输出

`需求确认` 结论一条（含验收标准＋路由清单），写入逻辑链：
`python ../../scripts/logic_chain.py add --from 需求确认 --to 编排设计 --why <结论>`。

## 红线

- 本体需求描述里不得复制专家技能内容（见
  [伞形不重复约束](../../resistance/伞形不重复约束/伞形不重复约束.md)）；
- 不得静默扩大范围；新增范围须回本步重确认。
