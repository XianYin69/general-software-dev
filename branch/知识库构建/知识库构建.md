# 知识库构建

沉淀本中枢技能**跨领域**经验：编排、门禁、路由判例，而非各语言专项细节。

## 步骤

1. 定位缺口：接 [经验查询/](../经验查询/经验查询.md) 的「未知缺口」清单。
2. 检索与验证：官方文档/原始仓库优先，记录 `source_url`；
   存 [../../references/references.md](../../references/references.md) 索引下。
3. 转化：把结论写成 ≤50 行的卡片（问题→判据→动作），可复用即入链。
4. 拓扑判定：反复追问「还能不能拆出新领域」，**不可再拓扑**才收本步。
5. 记 `process_chain.py save --step 知识库构建`。

## 边界

- 专项语言/API 细节归各专家技能知识库，本体不重复收录；
- 缓存与下载产物落用户缓存目录，不得写进 skill 目录（红线）。
