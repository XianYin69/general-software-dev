# 初始化（两条路径共同前置）

## 子节点

1. **建立工作空间**：确认目标 skill 目录；未指定时按
   [沙盒机制](../../resistance/沙盒机制/沙盒机制.md) 在固定路径建沙盒。
2. **加入 MIT 协议**：写 `LICENSE`（已有不覆盖）。
3. **建立计划任务目录**：`planned_tasks/README.md` ＋ `template.json`（已有不覆盖）。
4. **依赖自检**：`python ../../scripts/deps_check.py` 校验 `dependence/deps.json`
   每条含 `source_url`（本地技能 `local://<skill-id>`）。
5. **git 自动初始化**：无 `.git` 即 `git init`，并按
   [git工作流约束](../../resistance/git工作流约束/git工作流约束.md) 建功能分支。
6. **挂载机制**：五大机制约束见
   [../../resistance/resistance.md](../../resistance/resistance.md)。

## 退出条件

六项全绿并 `process_chain.py save --step 初始化`；缺任一项不得进
[需求确认/](../需求确认/需求确认.md)。

## 反例（禁止）

- 跳过 MIT/计划任务直接开写内容；
- 在 main/dev 上直接 commit；
- 把缓存/临时文件写进 skill 目录。
