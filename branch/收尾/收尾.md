# 收尾

## 步骤

1. **提示词**：确认 agent/ 四格式与 SKILL.md 入口一句话一致
   （CLAUDE.md / .cursorrules / instructions.md / agent_prompt.md）。
2. **自更新释放**：tmp 镜像经 `self_update.py compare` → `release --tmp <镜像> --target <skill>`，
   再 `clean`（见 [../../update/update.md](../../update/update.md)）。
3. **垃圾回收**：`python ../../scripts/garbage_collect.py --path <tmp>`（默认预览）。
4. **git**：功能分支 → dev（审核通过）→ main（整体审查通过）；推送前判可见性
   （[git工作流约束](../../resistance/git工作流约束/git工作流约束.md) 第 9、10 条：
   推送须用户确认；疑似违规/涉密须 PRIVATE）。
5. **计划任务**：核对 `planned_tasks/pt-*.json` 状态为 pending，不自行执行。
6. **返回**：标记「完成」，收口返回调度方整合续排（整段任务不因本技能完成而结束）。

## 红线

- 不得静默写盘；释放前必须 compare；
- 技能自身不得执行计划任务（到期由 SMS 调度器执行）；
- 不得直写 main/dev、未确认不得推送。
