# 经验查询

## 目的

动手前取既有经验，避免重复踩坑；本步只查不改。

## 步骤

1. 链检索：SMS 链 `chain recall`（memory/knowledge/logic/error），查既往同类项目与错误。
2. 本地知识：[../../references/references.md](../../references/references.md) 与依赖技能
   （[../../dependence/dependence.md](../../dependence/dependence.md)）的既有沉淀。
3. 联网补充：不确定处经依赖技能联网学习并回写知识链，禁止凭记忆臆造 API。
4. 汇总「可用经验／未知缺口」两栏，缺口转
   [知识库构建/](../知识库构建/知识库构建.md)。

## 退出条件

`process_chain.py save --step 经验查询 --data <两栏摘要>`；
缺口未登记不得进 [编排设计/](../编排设计/编排设计.md)。

## 红线

- 不得跳过本步直接设计；
- 检索结果与项目冲突时以验收标准为准，并记逻辑链。
