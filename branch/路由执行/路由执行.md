# 路由执行

本体按编排大纲把子任务派给专家技能，自己只做进度与验收。

## 步骤

1. 建任务表（复合诉求 ≥2 执行步），并行前提＝资源互斥（声明 `files=`/`port=`）。
2. 逐行派发：`skill` 工具真派发，只传意图＋参数＋验收标准（见
   [子技能路由/](../子技能路由/子技能路由.md)）。
3. 收口整合：读各子任务产物文件而非复述其文本；冲突回
   [编排设计/](../编排设计/编排设计.md) 重辩论。
4. 门禁流转：实现完成 → [打包发布/](../打包发布/打包发布.md) →
   [软件测试/](../软件测试/软件测试.md) → [git远端管理/](../git远端管理/git远端管理.md)。
5. 每行完成 `task_plan status done`；全行 done 才记
   `process_chain.py save --step 路由执行`。

## 红线

- 禁止把专家技能内容复制进本体目录（见
  [伞形不重复约束](../../resistance/伞形不重复约束/伞形不重复约束.md)）；
- 禁止空口声称已执行；宣告动手必须同轮派发或写盘；
- 子任务失败只重跑该行，不整体回退（除非惩罚熔断）。

## 降级

派发目标缺失或无响应 → 走
[降级策略](../../resistance/降级策略/降级策略.md)：改派同域替代技能，仍无则回退并如实报告。
