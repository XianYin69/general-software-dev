# 软件测试（子技能位 · 实体）
**状态：实体**——由子技能 [`software-testing`](../../../software-testing/SKILL.md) 承担，
本体只保留策略输入与门禁消费，不复制其用例与脚本。

## 交接接口
- 本体交付：验收标准（来自 [需求确认/](../需求确认/需求确认.md)）、被测目标、覆盖率阈值；
- 子技能交付：分层策略（单元/集成/端到端）→ 用例来源登记 → 执行 → 证据四件套与失败门禁；
- 声明位置：[../../dependence/deps.json](../../dependence/deps.json) 条目
  `local://software-testing`；Web 端到端由子技能再派 `webapp-testing`。

## 本体职责边界
1. 失败即中断：子技能给 `[FAIL]` → 本体记 `process_chain.py interrupt` 并回退对应步骤；
2. 禁修绿：不得为过门禁改写用例或阈值（证据口径由子技能约束持有）；
3. 本体目录不留测试脚本副本（[伞形不重复约束]
   (../../resistance/伞形不重复约束/伞形不重复约束.md)）。
