# 流程（主干总览）

本技能是**伞形中枢**：本体只做跨领域编排与横切环节，专项实现交给既有专家技能。

[初始化/](../初始化/初始化.md) → [需求确认/](../需求确认/需求确认.md) →
[经验查询/](../经验查询/经验查询.md) → [编排设计/](../编排设计/编排设计.md) →
[路由执行/](../路由执行/路由执行.md) → [知识库构建/](../知识库构建/知识库构建.md) →

[收尾/](../收尾/收尾.md) → 完成

## 横切环节归属（本体持有）

| 环节 | 本体做什么 | 派给谁 |
|---|---|---|
| 项目脚手架 | 目录/约定/README 决策 | 见 [编排设计/](../编排设计/编排设计.md) |
| 架构决策 | 分层与接口取舍、双链辩论 | 本体 |
| 编码实现 | 只传意图＋验收标准 | [子技能路由/](../子技能路由/子技能路由.md) |
| 打包发布 | 流程与门禁 | [打包发布/](../打包发布/打包发布.md)（实体→packaging-and-release） |
| 测试 | 测试策略与门禁 | [软件测试/](../软件测试/软件测试.md)（实体→software-testing） |
| 版本控制/远端 | 分支策略、PR、可见性判定 | [git远端管理/](../git远端管理/git远端管理.md)（实体→git-remote-management） |

## 机制挂钩

每步收尾记 `process_chain.py save --step <步名>`；决策记 `logic_chain.py add`；
审查失败记 `interrupt`；重试计数 `penalty.py hit`（达 10 熔断）。
