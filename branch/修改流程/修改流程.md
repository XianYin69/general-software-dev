# 修改流程（独立路径）

改本技能内容一律走「tmp 镜像 → compare → release」，禁止就地直写。

## 步骤

1. 明确变更范围与理由；涉及 resistance/ 须先过
   [../../update/update.md](../../update/update.md) 审批流。
2. 在 tmp 镜像改（每文件仍 ≤50 行、链接相对路径同步修正）。
3. 校验：`python ../../scripts/check_links.py` ＋ `python ../../scripts/check_len.py`
   ＋（涉依赖时）`python ../../scripts/lint_deps.py`。
4. 双链辩论确认变更方向：`python ../../scripts/logic_chain.py debate`。
5. 释放并清理：`self_update.py compare/release/clean`。
6. git：功能分支→dev→（整体审查通过）→main。
7. 标记「完成项目修改」并收口返回调度方。

## 红线

- 不得删除 resistance/ 约束、不得把行数红线放宽；
- 不得把专家技能内容搬进本体（伞形不重复）；
- 修改后悬空链接必须仍为 0。
