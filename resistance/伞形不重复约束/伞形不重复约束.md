# 伞形不重复约束

## 条件

本技能（中枢/伞形）在处理任何子任务、编写任何文档或脚本时。

## 必须

- 横切环节（脚手架/架构/打包/测试/远端）留在本体；
- 专项能力一律经 [路由派发约束](../路由派发约束/路由派发约束.md) 派发；
- 需要他技能规范时，只在 [deps.json](../../dependence/deps.json) 声明依赖并链接，不落副本；
- 判据：**换个语言栈还成立才留本体**（详见
  [GSD-001 中枢边界](../../references/编排判例/GSD-001-中枢边界.md)）。

## 禁止

- 复制 python-expert / cpp-expert / c-expert / frontend-dev / database-management /
  webapp-testing / create-pull-request / code-guidelines 的正文、脚本或约束进本目录；
- 在本体 SKILL.md 里罗列专项语言技巧清单（入口只留摘要与链接）；
- 为「方便」在被派发技能目录内写文件（越权写盘）。

## 违反后果

双份维护、规则冲突、上游技能更新不再生效，且难以定位是谁的错；
一经发现即删除副本并记逻辑链。
