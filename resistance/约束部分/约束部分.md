# 约束部分（红线区识别）

## 什么是红线区

命中以下任一特征的文本＝红线区，改动前须走 [update 审批流](../../update/update.md)：

- 含「必须／禁止／不得／即判不合格」字样的条目；
- 位于 [resistance/](../resistance.md) 全目录、SKILL.md「红线」小节、
  各审查节点清单；
- 依赖清单字段名、计划任务 schema 字段名（读取端契约）；
- 行数与链接校验规则（≤50 行、悬空链接＝0）。

## 处理规则

1. 红线区只可**加严**，不可放宽或删除；
2. 修改须在 `CHANGELOG.md` 留条目并写明动机与后果；
3. 与他技能红线冲突时：本体横切规则优先于自身，专项规则归专项技能，
   仍冲突则记逻辑链交派发方仲裁；
4. 非红线区（说明性正文）可自由精简，但不得引入悬空链接。

## 违反后果

契约破坏导致 SMS 读取端解析失败、校验形同虚设、跨技能规则互相覆盖。
