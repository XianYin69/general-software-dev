# 审查约束（项目级）

## 必须通过才允许收口

1. 悬空链接＝0（[check_links](../../scripts/check_links.py)）；
2. 全部 `.md` ≤50 行（脚本不限行数，但禁裸 except／print 调试残留／>100 字符长行／超长函数）；
3. 每条依赖附 `source_url`（本地技能 `local://<skill-id>`），lint 无错；
4. 计划任务：一任务一文件、字段名与 SMS 读取端一致、本地 ISO 时间、技能自身不执行；
5. SKILL.md 含 KiloCode YAML frontmatter（仅 name/version/description/license/metadata），
   入口一句话＝「使用 <skill名> skill 来完成用户请求」；
6. 目录标准齐备：agent/ 四格式＋asset/＋dependence/＋planned_tasks/＋branch/＋
   references/＋resistance/＋scripts/＋update/；
7. 伞形不重复（见 [伞形不重复约束](../伞形不重复约束/伞形不重复约束.md)）；
8. 占位条目未被擅自填充（见 [子技能位占位约束](../子技能位占位约束/子技能位占位约束.md)）；
9. git 历史符合 [git工作流约束](../git工作流约束/git工作流约束.md)。

## 失败处理

任一项失败 → `process_chain.py interrupt`，回对应步骤修复后 `resume`；
重试计数入 [惩罚机制](../惩罚机制/惩罚机制.md)。

## 禁止

- 放宽红线以「过审」（不得删除 resistance/ 约束）；
- 把「形式停止」当「实质完成」上报。
